# Abhishek Chauhan — Portfolio

Frontend engineer portfolio. Warm paper, editorial type, a quiet accent.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Console

**Alt + A** opens the config console.

- **Profiles** — GitHub, LinkedIn, Devpost, website, YouTube
- **GitHub** — fetch repos, import as work
- **Work** — live URL, YouTube demo, Devpost per project
- **Edu** — degrees
- Export JSON to persist beyond this browser

## Stack

Vite, React, Tailwind CSS v4, Framer Motion, Lenis.
